Privacy Policy

Gaya Prasad Lokai Ram School Fee Ledger System prioritizes student and financial data security.

1. Data Storage: All receipt records, student concessions, and payment ledger details are stored securely using Google Cloud Firestore with standard access security.

2. Usage: Student information (Name, Class, Parent Name) is strictly used for school administrative accounting, fee receipt generation, and report generation.

3. Data Integrity: Cloud synchronization ensures that records are preserved and accessible only by authorized staff members.

Help & Support

How to Issue a Receipt:

1. Enter Student Name and Class.

2. Choose Fee Items using Quick Add or manual rows.

3. Click Save to Google Cloud & Issue to generate the receipt number and log the payment permanently.

4. Click Print Receipt for parent paper copy.
